# Audio Assets

This directory contains audio files for Hex Dominion.

## Required Files

### SFX (`/audio/sfx/`)
- `click.mp3` - Button clicks, menu navigation
- `confirm.mp3` - Menu selection, action confirmation
- `cancel.mp3` - Escape key, cancel actions
- `select.mp3` - Unit selected
- `attack.mp3` - Unit attack
- `hit.mp3` - Damage impact
- `death.mp3` - Unit destroyed
- `build.mp3` - Unit produced at factory
- `capture.mp3` - Building captured
- `income.mp3` - Funds collected at turn start
- `turn-end.mp3` - Turn transition
- `victory.mp3` - Win the battle
- `defeat.mp3` - Lose the battle

### Music (`/audio/music/`)
- `menu.mp3` - Main menu / campaign screen
- `battle.mp3` - During gameplay

## Recommended Free Sources

### For SFX:
- [OpenGameArt 512 8-bit Sound Effects](https://opengameart.org/content/512-sound-effects-8-bit-style)
- [itch.io Sound Effect Packs](https://itch.io/game-assets/free/tag-sound-effects)
- [Pixabay Game Sounds](https://pixabay.com/sound-effects/search/game/)

### For Music:
- [Soundimage Chiptunes](https://soundimage.org/chiptunes/)
- [Patrick de Arteaga Chiptune](https://patrickdearteaga.com/en/chiptune-8-bit-retro/)
- [PlayOnLoop 8-bit](https://www.playonloop.com/royalty-free-music-style/8-bit/)

## Format
Use `.mp3` format for broad compatibility and good compression.
